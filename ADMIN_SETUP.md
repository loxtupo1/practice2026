# Быстрая настройка админки «Картриджа»

Для назначения администратора не нужны service-account ключ, Google Cloud CLI или платный тариф. Роль задаётся документом в Firestore, который создаётся вручную владельцем проекта в Firebase Console.

## Назначить себя администратором

1. Войди в сайт своим обычным аккаунтом.
2. В Firebase Console открой **Authentication → Users** и скопируй **UID** своего аккаунта.
3. Открой **Firestore Database → Data** и создай корневую коллекцию `admins`.
4. В коллекции `admins` создай документ, где **ID документа точно совпадает с UID** аккаунта. Добавь поле `enabled` типа Boolean со значением `true`.
5. Открой **Firestore Database → Rules**, вставь содержимое файла `firestore.rules` и нажми **Publish**.
6. Вернись на сайт и открой `/admin`. Если страница уже открыта — обнови её.

Админка позволяет просматривать общий каталог, добавлять, редактировать и удалять игры. Правила Firestore запрещают клиентам создавать или менять документы в `admins`, поэтому пользователь не может назначить себя администратором из сайта.

## Снять права администратора

В Firebase Console удали документ `admins/{UID}`. Роль обновится на сайте автоматически. Не удаляй документ другого пользователя.

> Важно: опубликованные правила защищают данные в Firestore. Не ограничивайся проверкой роли только в интерфейсе сайта.
